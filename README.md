# Memory Shared Primitives

![Development Status](https://img.shields.io/badge/status-active--development-blue.svg)

Shared-memory (shm) vocabulary — `Memory.Shared` namespace with `Error` types.

Sibling extraction of [swift-memory-primitives](https://github.com/swift-primitives/swift-memory-primitives). Syscall implementations live in platform packages — POSIX in [swift-iso-9945](https://github.com/swift-standards/swift-iso-9945) (`extension Memory.Shared`).
